---
name: evaluate-repo-issue-suitability
description: Evaluate a Github repo's issue suitability based on the specified goal
---

Assess a repo issue for suitability, to satisfy the specified goal. Fetch the issue details using the `get_repo_issue` tool.

E.g. If the issue has limited details, they are not beginner-friendly.

Return a verdict of Suitable/Not suitable for the issue.
